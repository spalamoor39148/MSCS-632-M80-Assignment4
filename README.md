# MSCS-632-M80-Assignment4
Employee Shift Scheduler
Overview

The Employee Shift Scheduler is a C++ program that automates the assignment of employees to various work shifts. It ensures fair and balanced shift allocation while demonstrating the use of arrays, vectors, randomization, and basic file handling in C++.

Objective

Automatically assign employees to Morning, Afternoon, or Night shifts.

Distribute workloads evenly across all employees.

Provide a foundation for more advanced scheduling systems.

Features

Automatic random shift assignment

Simple command-line output

Easy to modify and extend

Portable — works on macOS, Windows, and Linux
